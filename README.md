# 🏫 Web Kelas

Aplikasi web profil dan manajemen data kelas berbasis React. Dibangun sebagai proyek pembelajaran dengan fitur menampilkan informasi siswa, foto, dan data kelas secara dinamis.

---

## ✨ Fitur

- 👥 Tampilan profil dan data anggota kelas
- 🖼️ Foto siswa yang tersimpan di database
- 🔐 Sistem login admin untuk pengelolaan data
- ⚡ Data real-time dari Supabase

---

## 🛠️ Tech Stack

| Teknologi | Kegunaan |
|-----------|----------|
| **React.js** | Library frontend utama |
| **JSX (JavaScript)** | Bahasa pemrograman & struktur UI |
| **Tailwind CSS** | Styling & desain antarmuka |
| **Supabase** | Database (PostgreSQL) & autentikasi |

## 🚀 Cara Menjalankan

```bash
# 1. Clone repository
git clone https://github.com/daifa17/web-kelas.git

# 2. Masuk ke folder proyek
cd web-kelas

# 3. Install dependencies
npm install

# 4. Buat file .env dan isi dengan kredensial Supabase kamu
REACT_APP_SUPABASE_URL=your_supabase_url
REACT_APP_SUPABASE_ANON_KEY=your_supabase_anon_key

# 5. Jalankan aplikasi
npm start
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
